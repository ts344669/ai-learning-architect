# Развёртывание AI Learning Architect на GitHub + Render

## 1. GitHub
Создайте новый репозиторий, например `ai-learning-architect`.
Загрузите в корень репозитория содержимое этой папки, а не саму внешнюю папку.
Не добавляйте файл `.env` и реальные API-ключи. `.gitignore` уже подготовлен.

## 2. Render
Создайте новый **Web Service** из GitHub-репозитория.
Проект использует Node.js и запускается командой `npm start`.
Можно использовать находящийся в проекте `render.yaml`.

Рекомендуемые параметры:
- Runtime: Node
- Build command: `npm install`
- Start command: `npm start`
- Plan: Free
- Health check: `/api/health`

## 3. Environment variables в Render
Добавьте в Render, а не в GitHub:
- `GEMINI_API_KEY` = ваш ключ Gemini API
- `GEMINI_MODEL` = `gemini-3.5-flash-lite`
- `MAX_AI_CALLS_PER_DAY` = `20`
- `MAX_AI_CALLS_PER_IP_PER_DAY` = `4`

Render сам задаёт `PORT`, вручную его добавлять не нужно.

## 4. Проверка после Deploy
Откройте публичную ссылку и последовательно проверьте:
1. `/api/health`
2. Первый учебный пакет: учебный дефицит
3. Второй пакет: смешанная проблема
4. Третий пакет: неучебная причина
5. Собственную небольшую вымышленную задачу

Важно: Free Web Service Render может засыпать после периода бездействия; первый запуск после паузы может занять около минуты.

## 5. Ограничение ответственности и методологии
Бизнес-KPI, числовые цели, сроки и критерии результата задаёт заказчик. AI Learning Architect не гарантирует достижение KPI и не должен приписывать весь прирост показателя обучению.
